# Учебный журнал

Spring Boot REST API и простой веб-интерфейс для просмотра и управления студентами.

## Запуск

Нужны Java 21+ и PostgreSQL. Приложение по умолчанию подключается к `students_db` на `localhost:5432` с пользователем и паролем `postgres`. Создайте базу данных перед запуском:

```sql
CREATE DATABASE students_db;
```

Запустите приложение:

```bash
./mvnw spring-boot:run
```

Откройте [http://localhost:8080](http://localhost:8080). При первом запуске создаются демонстрационные учётные записи:

| Роль | Почта | Пароль |
| --- | --- | --- |
| Администратор | `admin@example.com` | `admin` |
| Преподаватель | `teacher@example.com` | `teacher` |
| Суперадминистратор | `superadmin@example.com` | `superAdmin` |

Администратор может добавлять, редактировать контакты и удалять записи. Преподаватель имеет доступ только для чтения. Демонстрационные пароли предназначены только для локального запуска.

## Тесты и покрытие

Запустите тесты и сформируйте отчёт JaCoCo. `verify` также проверяет, что покрытие инструкций не ниже 75%:

```bash
./mvnw clean verify
```

HTML-отчёт покрытия будет доступен в `target/site/jacoco/index.html`.
